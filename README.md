# 📊 Excel Sales Dashboard

## 📌 Project Overview

This project is an interactive Sales Dashboard created in Microsoft Excel using charts, KPIs, and Pivot Tables.

## 📈 KPIs

- Total Sales
- Total Quantity
- Products
- Regions

## 📊 Charts

- Product Wise Sales
- Region Wise Sales
- Category Wise Sales
- Sales Person Performance

## 🛠 Tools Used

- Microsoft Excel
- Pivot Table
- Pivot Chart
- Slicers
